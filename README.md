# FAO Science and Innovation Strategy: course redesign concept (Lesson 1)

A portfolio piece by Erik Sootla: a redesign of Lesson 1 of the FAO self-paced e-learning course on the FAO Science and Innovation Strategy.

- Plain-language text written from scratch, task-based learning outcomes, role-based practice tasks with feedback.
- Runs in any browser and as a SCORM 1.2 package (completion, score and bookmark are reported to the LMS).

Based on the FAO e-learning course on the FAO Science and Innovation Strategy (2025). Not an official FAO product.
